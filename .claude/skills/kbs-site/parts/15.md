### 8. 站長後台 `/admin`（2026-11-25 起，2026-11-26～27 大改）

只有站長進得去；公開頁沒有任何連結（首頁導覽列的「登入」→ `/login` 分「站長登入」「訪客參觀」）。沒登入的外部請求一律 404。
**部落格寫過的對應文章**：`sqlite-wal-vacuum-into-backup`、`sqlite-fts5-trigram-chinese-search`（系列「站長後台」）。

#### 頁面（`src/app/admin/`，分頁列 `lib/admin/nav.ts`）
總覽、報表（`/admin/reports`，內容在 `components/admin/ReportsView.tsx`，公開的 `/reports` 已改 404）、流量、維運、寄信、樹莓派（`/admin/pi`）、待辦、完成（`/admin/done`）、搜尋（`/admin/search`，每個後台頁頂端也有搜尋框）。
- 資料／畫面分兩層：`lib/admin/views.ts` 產 `ViewModel`、`components/admin/AdminView.tsx` 畫；訪客參觀 `/demo/admin` 用 `lib/admin/demo-data.ts` 的範例資料（**沒有**「完成」頁，那是站長自己的流水帳：`nav.ts` 的 `private: true`）
- 每個頁面照 `/radar` 的 Cache Components 寫法：`<Suspense>`＋內容元件第一行 `await connection()`
- 報表頁含：真人訪客、流量、維運、雷達、機場、**外部連結點擊（/go/）**、**Web Vitals（桌機＋手機分開）**、**Google 搜尋字詞（Search Console 每天快取）**、網站更新
- 後台專用色 `--ok`／`--later`（＋`-lt`）、`--warn-lt`，**公開頁不要用**

#### 資料庫 `data/admin.db`（`lib/admin/db.ts`，SQLite，Node 24 內建 `node:sqlite`，不用裝套件）
- 版本用 `PRAGMA user_version`，加欄位／表就在 `MIGRATIONS` 後面加一段，**不要改舊的**。**WAL 模式**（2026-11-27）：備份**不能直接複製 .db**，用 `node scripts/admin-db.js backup <檔>`（`VACUUM INTO`＋`integrity_check`，`backup.ps1` 已這樣做）
- 表：`decisions`（決策）、`admin_log`（操作紀錄，留 1000 筆）、`todos`（待辦正本）、`logins`、`done_log`（完成紀錄正本）、`search`（FTS5 trigram，migration 5，用 trigger 跟 todos／done_log／admin_log 同步）
- 在桌機才有（不進 git）；A14 讀不到。測試用 `ADMIN_DB_FILE=:memory:`
- **FTS5 地雷**：未索引欄位用 `src LIKE 'todo%'` 刪除會刪 0 筆，用 `src IN (...)`；trigram 搜不到 2 個字的詞（`searchAdmin` 會退回 LIKE）

#### 命令列 `node scripts/admin-db.js`（用法寫在那支檔案開頭）
`todo`（列出）／`todo show|add|edit|done|drop|reopen`／`todo ask <id> "問題"`（Claude 的問題，後台紫色框＋「Claude 有問題」標籤）／`todo say`／`decisions`／`done`（`show|search|add|import`）／`search <字>`／`backup <檔>`／`log`。
`todo done` 會自動補一筆完成紀錄，待辦頁沒有「已完成」分頁，歷史只看 `/admin/done`（多項合併敘述才另外 `done add`）。`parseDone`（舊 DONE.md 匯入）在 `scripts/lib/parse-done.js`。

#### 多個 Claude session 一起改這個 repo 時（2026-11-26～27 踩過）
- **commit 只 add 自己的檔案**（`git add -A src` 會夾帶別人改一半的檔；混在同一個檔的用 `git apply --cached` 只放自己的 hunk）
- **部署是在桌機這個工作目錄 `git pull`＋build**，所以別人未 commit、改到一半的檔案會被一起 build（11/26 18:10 的部署因此失敗）；push 前確認 `tsc` 通過
- **本機驗證用自己專屬的 build 資料夾**（例 `.next-test3`）＋自己的 port（3201），不要都用 `.next-test`／3200：互相蓋掉 chunk 會造成 E2E 大量假失敗
